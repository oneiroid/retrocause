Each alternative has a short label, the character whose action it is, its event expr, a state note describing what is now true, a delta naming the one thing that changed from the told story, and invariants naming what stayed the same. Use only the characters, places and things of the told story you are given — never ones from an earlier example. Every alternative says where it goes next as rejoin: the bracketed id of the told state it leads back into, or none if it leaves the told story for good.
